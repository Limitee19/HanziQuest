# OmniLife — Design System Specification

**Project:** OmniLife  
**Module:** Consolidated Design System Tokens (Phase 25)  
**Date:** August 12, 2026  

---

## 1. Overview

The OmniLife Design System establishes a calm, modern, human productivity aesthetic following the **"Not Too AI" Principle**. It eliminates hyper-neon gradients and chaotic visual clutter in favor of clean typography, subtle borders, semantic colors, and touch-friendly target areas.

---

## 2. Design Tokens

### Semantic Color Scale:
- **Primary**: Blue-600 (`#2563EB`)
- **Secondary / Muted**: Zinc-500 (`#71717A`)
- **Background (Light)**: White / Zinc-50 (`#FAFAFA`)
- **Background (Dark)**: Zinc-950 (`#09090B`)
- **Surface**: Zinc-900 / Zinc-100
- **Success**: Emerald-500 (`#10B981`)
- **Warning**: Amber-500 (`#F59E0B`)
- **Error**: Red-500 (`#EF4444`)

### Typography & Spacing:
- **Font Stack**: Inter, system-ui, sans-serif
- **Spacing Scale**: 4px, 8px, 12px, 16px, 24px, 32px
- **Border Radius**: 8px (`rounded-lg`), 12px (`rounded-xl`), 9999px (`rounded-full`)
- **Touch Target Minimum**: 44x44px for touch interactive controls
